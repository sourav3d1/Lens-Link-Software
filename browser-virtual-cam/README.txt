LensLink Browser Virtual Webcam Extension v1.2 (No OBS Studio Required)
======================================================================

Use your paired smartphone camera directly inside Google Meet, Zoom Web,
Microsoft Teams Web, BIS Hallmarking portals, and any browser website
without installing OBS Studio, Python, Windows drivers, or a WebSocket server.

What's New in v1.2:
- Low-latency async WebP/JPEG frame relay (zero UI stutter, ~70% less CPU).
- Latest-frame-wins renderer prevents any latency buildup during calls.
- Works seamlessly with both standard Chrome tabs and installed Chromium PWAs.

3-Step Installation (Chrome or Microsoft Edge):
1. Extract this entire ZIP folder to a permanent location on your PC.
2. Open chrome://extensions (Chrome) or edge://extensions (Edge)
   and turn ON "Developer mode" in the top-right corner.
3. Click "Load unpacked" and select this extracted folder.
   (If upgrading from v1.0/v1.1, replace the old folder files and click the
    Reload icon on LensLink Virtual Webcam in chrome://extensions.)

How to Use:
- Keep your LensLink PC Receiver window open with your smartphone streaming.
- Open Google Meet, Zoom Web, Teams Web, or any browser portal.
- Select "LensLink Wireless Camera" in the site's camera settings
  (or click the LensLink extension icon -> toggle "Set as Default Camera"
  for portals that do not show a camera dropdown).
